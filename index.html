    Ask your agent

    Open Claude Code, or any agent that can read a SKILL.md, in the folder that holds this page. Paste one of these with your own app or folder in it. The included launchpad-add-cell skill checks each launcher on your machine, shows a dry run and writes only what you approve. It needs Arch-based Linux with pacman.
