Startclip is a startup map for the apps on your own machine: Docker stacks, local model servers, AI agents and desktop tools. It is one HTML file that works offline. It starts empty, and you fill it with your own apps.

Download Startclip

The film did not load. Open it on its own.

    The film opens on a wall of start commands and the line: you installed it, you forgot how to start it. A terminal fails because the Docker engine is not running. A click on a Startclip card copies the command with its prerequisite, and nothing runs. The map draws the startup chain, the inspector lists its steps, and four model servers are flagged for sharing a port.

    Startclip cannot start anything, and that is the point.

    No execution
    There are no URL schemes, no local helper and no background service. The page writes to your clipboard and stops there.
    No network
    A Content-Security-Policy of default-src 'none' blocks every request. There are no fonts, scripts or images to fetch.
    No install
    It is one index.html with no framework and no build step.
    No account, no telemetry
    Your workspace order, recent copies and theme stay in your browser's local storage.
